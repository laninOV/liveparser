# liveparser

Расширение Chromium/Яндекс Браузера для сбора настольного тенниса, формирования прогнозов на 2+ сета, отправки в Telegram и ведения локального архива.

Расширение работает на том источнике, страницу которого вы открыли: BetsAPI или BSportsFan. Для каждого запроса сначала используется открытый источник, затем — его близнец. Отдельные запросы не меняют маршрут следующих матчей. Сама вкладка переключается только при подтверждённой видимой защите, истечении сессии или нераспознаваемой странице. Архив у обоих источников единый и связывается по числовому ID матча.

## Установка

1. Откройте страницу управления расширениями в Яндекс Браузере.
2. Включите режим разработчика.
3. Выберите «Загрузить распакованное расширение» и укажите эту папку.
4. Откройте один из источников и оставьте вкладку открытой:
   - `https://betsapi.com/cip/table-tennis`
   - `https://ru.bsportsfan.com/cip/table-tennis`

Открывать несколько рабочих вкладок не требуется. Если вручную открыть другой источник в новой активной вкладке, сбор перейдёт в неё; прежняя вкладка станет пассивной. Кнопка «Перезапуск» очищает зависшие очереди и старые паузы источников, не удаляя архив и настройки Telegram.

Текущая версия указана в `manifest.json`.

## Данные

Объединённые выгрузки находятся в `exports/`. Настройки Telegram и рабочее состояние браузера в Git не сохраняются: они хранятся локально в профиле расширения.

Не добавляйте в репозиторий токены Telegram, пароли и другие секреты.
