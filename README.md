# liveparser

Расширение Chromium/Яндекс Браузера для сбора настольного тенниса, формирования прогнозов на 2+ сета, отправки в Telegram и ведения локального архива.

BetsAPI используется как основной источник, BSportsFan — как автоматический резерв. Расширение само выбирает один активный сборщик, переключает источник при защите или истечении сессии, возвращается на основной после восстановления и продолжает вести единый архив по числовому ID матча.

## Установка

1. Откройте страницу управления расширениями в Яндекс Браузере.
2. Включите режим разработчика.
3. Выберите «Загрузить распакованное расширение» и укажите эту папку.
4. Откройте `https://betsapi.com/cip/table-tennis` и оставьте вкладку открытой.

Открывать несколько рабочих вкладок не требуется: расширение само оставляет только одного активного сборщика. Кнопка «Перезапуск» очищает зависшие очереди и старые паузы источников, не удаляя архив и настройки Telegram.

Текущая версия указана в `manifest.json`.

## Данные

Объединённые выгрузки находятся в `exports/`. Настройки Telegram и рабочее состояние браузера в Git не сохраняются: они хранятся локально в профиле расширения.

Не добавляйте в репозиторий токены Telegram, пароли и другие секреты.
